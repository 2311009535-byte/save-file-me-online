# Save File: Me

可运行的互动叙事框架。使用原生 HTML、CSS、JavaScript 和 Node.js 静态服务，不需要安装应用依赖。所有场景直接占满浏览器内容区，无导航、品牌栏、卡片或页面滚动条。场景按原始比例尽可能放大，不裁切、不拉伸；比例不一致时留黑边。图片、热区、角落返回按钮共用一个场景缩放变换。屏幕比例差异很大时，黑边也会更大，这是完整保留画面所需。

## 打开作品

1. 在终端进入项目：`cd /workspace/save-file-ME`。
2. 输入 `npm start`，看到 running on port 3000 即启动成功。
3. 如果平台有端口预览入口，选择端口 **3000**。如果将项目下载到自己的电脑，在项目文件夹运行 `npm start` 后，用浏览器打开 `http://localhost:3000`。

云端 localhost 属于云端机器；在自己电脑浏览器输入它不会直接连接云端。当前工具没有提供可分享的云端预览地址。

## 体验和验收

按入口顺序进入 Wonder → Escape → Retry & Connection → Creation，使用序章内的窗户、灯、电脑、门进入章节。按 `Shift+D` 打开开发面板，点击“临时完成当前章节”，再按 `Shift+D` 或 `Esc` 隐藏面板。每次回到对应的 0_1 / 0_2 / 0_3 / 0_4 序章图。四章完成后点击序章画面中的门（EXIT GAME）进入 Final。

中途返回不会通关。刷新会恢复章节或序章和完成进度。已完成章节可以回看，进度不会倒退。存档保存在当前浏览器、当前站点的 localStorage，不跨设备或不同预览域名同步。

开发面板默认隐藏，按 `Shift+D` 切换，`Esc` 关闭；提供正常进入、测试跳转、模拟完成与重置。跳转高章节会启用前置进度；模拟完成写入所选进度；重置需要确认。

## 固定在线地址与 GitHub 自动更新

项目支持 Netlify 和 Vercel 静态部署，无后端、数据库、部署秘密或付费服务依赖。仓库中的 `netlify.toml` 和 `vercel.json` 已指定运行 `npm test` 后发布 `public`。不要用 `npm start` 作为在线平台的构建命令。

### Netlify（推荐，只需要首次设置）

1. 打开 https://app.netlify.com/ 并用 GitHub 登录。
2. 选择 Add new project / Import an existing project，选择 GitHub。
3. 授权 Netlify 访问 `2311009535-byte/save-file-ME`，然后选择该仓库。
4. 现有正式网站使用 **save-file-me-framework**，开发期间不要更改或推送此分支。预览请按下面的新流程配置。
5. Base directory 留空；Build command 为 `npm test`；Publish directory 为 `public`。配置文件会自动提供这些值，不需要环境变量。
6. 点击 Deploy。等到显示 Published，打开平台实际给出的 HTTPS 网站地址。
7. 以后打开这个固定的站点主地址检查作品。推送到该分支会自动更新；不要收藏每次部署的临时网址。自动发布后如仍显示旧版，刷新页面。

### Vercel（备选，任选一个平台即可）

1. 打开 https://vercel.com/new 并用 GitHub 登录，导入同一仓库。
2. Framework Preset 选择 Other，Root Directory 使用仓库根目录。配置文件已指定 Build Command 为 `npm test`、Output Directory 为 `public`。
3. 部署后在 Project Settings → Environments → Production 中将 Branch Tracking / Production Branch 设为 **save-file-me-framework**（若平台最初使用 main，修改后对该分支重新部署）。
4. 在 Deployments 中确认该分支已成功部署为 Production，并打开项目主域名。以后此分支推送自动更新该固定地址。

以上配置已保存到 GitHub，并不代表在线平台已连接或部署成功。需要用户登录平台、授权仓库并完成第一次部署。只使用平台实际生成的域名，不猜测域名。

存档属于浏览器中的同一个站点：从 localhost 换到在线地址时会有新的存档；后续在同一固定地址更新代码会保留进度。HTTPS 在线地址支持摄像头拍照与本地手势识别；头像 AI 生成为本次试玩关闭。部署后请在站点按 Shift+D 打开测试面板，走完四章、刷新确认保存、测试重置。
